# Skills-Verzeichnis

Der Agent liest diese Liste und lädt einen Skill nur, wenn der Satz zur Aufgabe passt.
Neuer Skill = ein Eintrag hier (macht der Skill Creator in Phase 6).

| Skill            | Zweck in einem Satz                                        |
|------------------|------------------------------------------------------------|
| skill-creator    | Erstellt, prüft, testet und verbessert Skills.             |
| commit-message   | Schreibt Commit-Nachrichten im Format "T07: Kurztext".     |

Hinweis: commit-message ist zugleich ein Muster für eigene Skills.
Kopiere den Ordner, benenne ihn um und passe ihn an.
