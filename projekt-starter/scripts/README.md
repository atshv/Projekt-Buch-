# scripts/

Hilfsskripte, die man nicht täglich aufruft: Build, Daten importieren, aufräumen,
veröffentlichen. Alltägliche Befehle gehören nach bin/.

Regeln für jedes Skript:
- Oben 2 Zeilen Kommentar: was es tut, wie man es aufruft.
- Klare Fehlermeldungen, bricht bei Fehlern ab.
- Löscht oder überschreibt nichts ohne Rückfrage.
- Wird in dieser Datei mit einer Zeile eingetragen.
