# docs/design/prototype/

Hier liegt der Prototyp: der Massstab, an dem der UI-Judge die fertige Oberfläche misst.

Erlaubt sind:
- klickbare HTML-Dateien (z. B. start.html, bericht.html)
- Bilder je Bildschirm, nummeriert: 01-start.png, 02-liste.png, ...
- ein Link zu einem Design-Werkzeug, eingetragen in diese Datei

Regeln:
- Dateinamen tauchen in docs/design/SCENARIOS.md unter "Prototyp-Stelle" auf.
- Ändert sich der Prototyp, wird das Datum hier notiert und DESIGN.md geprüft.
