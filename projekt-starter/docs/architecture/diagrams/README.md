# docs/architecture/diagrams/

Diagramme als Text, damit sie versioniert und von der KI geändert werden können.

Regeln:
- Quelle als Mermaid-Datei: `name.mmd`. Daneben das Bild mit gleichem Namen: `name.svg`.
- Nach jeder Änderung der Quelle das Bild neu erzeugen (Befehl in AGENTS.md, Abschnitt Befehle).
- Namen in Diagrammen stimmen mit docs/GLOSSARY.md überein.
- Ein Diagramm, eine Frage: Überblick (wer spricht mit wem), Datenmodell, Ablauf.
