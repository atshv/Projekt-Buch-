# docs/integrations/

Eine Datei pro Verbindung zu einem fremden System: `int-0001-<von>-nach-<nach>.md`.
Nur anlegen, wenn das Projekt wirklich mit anderen Systemen spricht.
Inhalt: Zweck, Richtung, Auslöser, Daten (Felder), Format, Fehlerfall, Wiederholung, Besitzer.
Namen der Systeme und Daten stimmen mit docs/GLOSSARY.md überein.
