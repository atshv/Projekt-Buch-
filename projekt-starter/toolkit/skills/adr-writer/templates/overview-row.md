# Format der ADR-Übersicht (docs/adr/_overview.md)

```markdown
# Entscheidungen (ADR-Übersicht)

| Nr       | Titel                                              | Status      | Bezug     | Zuletzt geändert |
|----------|----------------------------------------------------|-------------|-----------|------------------|
| adr-0001 | [Titel](adr-0001-titel.md)                         | angenommen  | M1, P01   | 2026-01-15       |
| adr-0002 | [Titel](adr-0002-titel.md)                         | ersetzt durch adr-0004 | M3 | 2026-02-02 |
```

Regeln: eine Zeile pro ADR, sortiert nach Nummer, Link relativ, Datum JJJJ-MM-TT.
